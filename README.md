# الحبكة - The Plot Game 🎮

لعبة حفلة تفاعلية تجمع بين الاستنتاج والخداع والإقناع لـ 3-8 لاعبين.

## ⚡ البدء السريع

### المتطلبات
- Node.js v22+
- تطبيق Expo Go (للموبايل)

### التثبيت والتشغيل

```bash
git clone https://github.com/YourUsername/plot-game.git
cd plot-game
npm install
npm start
```

يقوم `npm start` بـ:
1. ✅ تشغيل خادم Node.js على المنفذ 3000
2. ✅ تشغيل Expo على المنفذ 19000

### الوصول إلى اللعبة

| الجهاز | الرابط |
|--------|--------|
| Host (PC) | `http://localhost:3000` |
| Admin Dashboard | `http://localhost:3000/admin` |
| Player (Mobile) | Expo Go + QR Code |

## 🆕 آخر التحديثات (v3.2.0) — نظام التصميم V2 🗂️

### 🎨 نظام تصميم V2 "Classified Dossier"
- ✅ **تصميم كامل موازٍ**: 19+ ملف في `design-v2/` — V1 و V2 يعملان جنباً إلى جنب
- ✅ **تخطيط ثلاثي ثابت**: شريط علوي (كود الغرفة/الدور) + منطقة لعب + أزرار سفلية — بدون تمرير
- ✅ **ثيمان light/dark**: ورق كرافت (#E8DDB5) للفاتح، نوار داكن (#080D18) للداكن
- ✅ **استجابة كاملة**: جوال عمودي + أفقي + ويب ديسكتوب (RTL-first)
- ✅ **ملف الدور**: نقر على الدور → modal يعرض الوصف، الهدف، القدرة، نتيجة التحقيق
- ✅ **زر الثيم ☀️/🌙**: في كل شاشة لتبديل الوضع الداكن/الفاتح فوراً
- ✅ **زر الريفرش ↺**: إعادة تحميل التطبيق من أي شاشة
- ✅ **V2 هو الافتراضي الآن** — يمكن التبديل لـ V1 من القائمة

### 🔧 إصلاحات تقنية
- ✅ **`npm start` أكثر ذكاءً**: يكتشف المنفذ المشغول ويقتل العملية تلقائياً (netstat + taskkill)
- ✅ **إصلاح Ctrl+C**: توقف الخادم يعمل بشكل صحيح عند الضغط على Ctrl+C


- ✅ **توليد أفاتار عشوائي**: أصبح لكل بوت أفاتار فريد (وجه، شعر، ملحقات، ألوان) عند إضافته للغرفة.
- ✅ **تنوع كرتوني**: إضافة خيارات ألوان بشرة فاقعة وتفاصيل مضحكة لزيادة حيوية الشخصيات.

### 🛠 إصلاحات ودعم الإدارة
- ✅ **إصلاح لوحة المشرف**: تصحيح عرض البيانات الديناميكية (عدد الغرف واللاعبين) التي كانت تظهر كرموز برمجية.
- ✅ **تحديثات تلقائية**: لوحة المشرف تعرض الآن الحالة الحقيقية للغرف واللاعبين لحظياً.

### 🎨 تحسينات واجهة المستخدم (UI/UX)
- ✅ **شارات اللاعبين (Badges)**: تظهر شارات اللاعبين الآن في جميع الشاشات (الغرفة، التصويت، النقاش) لسهولة التعرف عليهم.
- ✅ **اختيار الثيم**: إمكانية اختيار الثيم الداكن أو الفاتح يدوياً من الشاشة الرئيسية.
- ✅ **تحسين التخطيط**: رفع المكونات في صفحات "التدريب" لضمان ظهور جميع الأزرار دون الحاجة للتمرير.
- ✅ **دمج شارات الأدوار**: تظهر الشارات الآن فوق بطاقات السيناريو وتحتها بشكل جمالي لا يغطي النص.

## 🎮 كيفية اللعب

### 1. الإعداد
- **المضيف (PC):** ينشئ غرفة ويشارك الرمز (4 حروف). يضغط **"🤖 تعبئة بوتات"** لملء الفراغات.
- **اللاعبون (Mobile):** يدخلون الرمز واسمهم.
- **التدريب الفردي:** اختر دورك، وسيملأ النظام الغرفة ببوتات آلياً.

### 2. الأدوار (V4)

| الفريق | الدور | الميزة |
|--------|-------|---------|
| 🔵 العدالة | المحقق | يفحص لاعباً — يصله الرد عند النقاش |
| 🔵 العدالة | الشاهد | يرى كلمات مفتاحية |
| 🔵 العدالة | العرّاف | ينسخ القصة الحقيقية تلقائياً |
| 🔵 العدالة | الوزير | يعرف المحقق والمستفيد |
| 🔴 الجريمة | الجاني | يعرف القصة كاملاً |
| 🔴 الجريمة | العقل المدبر | يعرف فريق الجريمة ويوجّه الرشاوى |
| 🔴 الجريمة | المخرب | يقلب نتيجة فحص المحقق |
| 🔴 الجريمة | المستفيد | يبدأ بنقاط إضافية |

### 3-6. مراحل اللعب
**الكتابة (90ث)** → **العرض التشويقي** → **النقاش (120ث)** → **التصويت** → **النتائج**
