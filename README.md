# الحبكة - The Plot Game 🎮

لعبة حفلة تفاعلية تجمع بين الاستنتاج والخداع والإقناع لـ 3-10 لاعبين.

## ⚡ البدء السريع

### المتطلبات
- Node.js v22+
- npm أو yarn
- تطبيق Expo Go (اختياري للموبايل)

### التثبيت والتشغيل

```bash
# استنساخ المشروع
git clone https://github.com/YourUsername/plot-game.git
cd plot-game

# تثبيت الملفات
npm install

# التشغيل
npm start
```

**هذا الأمر سيقوم بـ:**
1. ✅ بدء تشغيل خادم Node.js على المنفذ 3000
2. ✅ بدء تشغيل Expo على المنفذ 19000
3. ✅ عرض رمز QR Code للمسح الضوئي

### الوصول إلى اللعبة

**الشاشة الرئيسية (Host):**
- افتح المتصفح: `http://localhost:3000/host.html`

**الهاتف (Player):**
- ثبت Expo Go من متجر التطبيقات
- امسح رمز QR Code من Terminal

## 🎮 كيفية اللعب

### 1. إعداد اللعبة
- **المضيف (Host/PC):** ينشئ غرفة ويشارك الرمز (4 حروف). يمكنه الضغط على زر "🤖 تعبئة بوتات" لملء الأماكن الفارغة بروبوتات ذكية قبل البدء.
- **اللاعبون (Players/Mobile):** يدخلون الرمز واسمهم للانضمام. التطبيق يدعم الوضعين **الأفقي والعمودي** لتجربة أفضل.
- **التدريب الفردي:** يمكن للاعب اختيار "تدريب فردي"، تحديد دوره المفضل، ثم إدخال رمز الغرفة. سيقوم النظام تلقائياً بملء الغرفة ببوتات لتدريبه.
- **الهوية البصرية:** تتميز اللعبة بنمط **Bureaucratic Noir** (ملفات الاستخبارات القديمة) مع واجهة مستخدم احترافية وخطوط واضحة.
- Host ينقر "بدء المهمة" (الحد الأدنى 3 لاعبين).

### 2. توزيع الأدوار (V4 Rules)
تتلقى كل لاعب دوراً سرياً ضمن فريقين:

**فريق العدالة (Justice Team) 🔵:**
- **المحقق (Detective)**: يكشف فريق لاعب واحد.
- **الشاهد (Witness)**: يرى كلمات مفتاحية من القصة الحقيقية.
- **العرّاف (Seer)**: يمكنه نسخ القصة الحقيقية دون رؤيتها.
- **الوزير (Minister)**: يعرف من هو المستفيد والمحقق.

**فريق الجريمة (Crime Team) 🔴:**
- **الجاني (Culprit)**: يعرف القصة الكاملة.
- **العقل المدبر (Mastermind)**: يعرف جميع أعضاء فريقه.
- **المخرب (Saboteur)**: يختار لاعباً لقلب نتيجة فحص المحقق عليه.
- **المستفيد (Beneficiary)**: يبدأ بنقاط إضافية.

### 3. مرحلة الكتابة (90 ثانية)
اكتب تبريراً لـ 140 حرف حول السيناريو

### 4. مرحلة العرض (10 ثوانٍ)
شاهد جميع الإجابات على الشاشة الرئيسية

### 5. مرحلة التصويت
- صوت لأفضل إجابة
- تخمين من هو الشاهد

### 6. النتائج
شاهد النقاط والترتيب

## 🖥️ تحسينات الويب (Web Optimization) 🆕

تم إعادة تصميم واجهة الويب بشكل كامل لتوفير تجربة استخدام مثالية على الشاشات الكبيرة:
- **تصميم متجاوب (Responsive Layout)**: استخدام هوك `useResponsiveLayout` لتكييف الواجهة ديناميكياً مع تغيير حجم النافذة.
- **وضع الـ Landscape**: استغلال 90% من عرض الشاشة لتقليل التمرير وعرض المعلومات بشكل مكثف (Dense UI).
- **مكونات ذكية**: الأزرار، البطاقات، والنصوص تتكيف أحجامها تلقائياً بين الموبايل (Touch-friendly) والويب (Mouse-friendly).
- **تجربة "No-Scroll"**: تحسين شاشات المضيف لتظهر جميع المعلومات الحيوية دون الحاجة للتمرير لأسفل.
